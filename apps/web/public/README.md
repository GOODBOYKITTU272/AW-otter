# Public Assets

## Logo Assets

Place the following logo files in this directory:

- `logo_Applywizz.png` - Main ApplyWizz logo
- `logo_echo.png` - Otter Echo logo (if available)

These logos will be displayed on the branded landing page and throughout the application.

## Brand Guidelines

- **Colors**: Jet Black #1E1E1E, Fluorescent Green #29FE29, Bright Blue #2C76FF, Soft Gray #F5F5F5, Navy #0B1D33
- **Fonts**: Noto Sans (primary)
- **Style**: Round CTAs, modern UI with best UX practices
